# Site statique sur GitHub Pages, données collectées par une tâche GitHub Actions planifiée

Le site est hébergé gratuitement sur GitHub Pages, sans serveur. Les données partagées (matchs, scores, joueurs, résumés) sont récupérées par une tâche GitHub Actions planifiée, sans clé API, qui publie des fichiers de données statiques lus par le site. Ce choix garantit 0 €/mois. La recherche des diffuseurs est l'exception : elle se fait sur l'appareil (voir ADR 0003). En contrepartie : pas de temps réel par la collecte (les tâches planifiées de GitHub tournent avec 5 min à plusieurs heures de retard ; le Score en direct est lu par l'appareil, voir ADR 0004), pas de comptes utilisateurs (réglages stockés sur chaque appareil), et un dépôt public obligatoire sur un compte GitHub gratuit.

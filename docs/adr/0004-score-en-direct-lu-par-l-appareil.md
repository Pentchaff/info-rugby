# Score en direct lu par l'appareil, directement chez ESPN

Les tâches planifiées de GitHub tournent avec des heures de retard (ADR 0001) : impossible de suivre un Match en cours par ce biais. Pour le Score en direct, c'est donc le navigateur qui interroge l'API ESPN (la même qu'ADR 0002), toutes les 30 secondes, et seulement quand un Match est en cours ou commence dans le quart d'heure et que la page est à l'écran. Un test depuis le téléphone (novembre 2026) a confirmé qu'ESPN accepte ces appels directs. On écarte un relais (Cloudflare Workers ou autre) tant que ce n'est pas nécessaire, et les API de scores payantes (règle des 0 €). En contrepartie : si ESPN bloque un jour les appels depuis un navigateur, le direct s'arrête (l'app garde le dernier score et affiche « Direct indisponible ») et il faudra ce relais ; pas de notifications (il faudrait un serveur) ; la Feuille de match et les marqueurs restent mis à jour par la collecte planifiée.
